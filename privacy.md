# Privacy Policy

Humble New Tab Page does not send user data to developer-operated servers and does not sell or share user data for advertising.

When browser synchronization is available, the extension stores its settings and portable layout metadata in the browser-provided extension sync storage (`chrome.storage.sync` / equivalent). This may be synchronized through the user's browser account provider. The synchronized layout metadata can include bookmark folder titles and structural references needed to reproduce the column layout on another browser profile. The extension does not upload the full bookmark database to a developer-operated service.

Local-only state, including the current open/closed folder state and locally selected background-image file data, remains in browser-local extension storage and is not intentionally written to the extension sync area.

- (Firefox only) To display website icons, the domain names of websites shown may be shared with the user-selected third-party favicon provider. This is configurable in the options.
